### [HireFlow](https://hire-flow-omega.vercel.app) — Hiring & Resume Processing Platform
*Solo full-stack build, following a structured six-phase engineering blueprint.*

A backend-depth portfolio project built to demonstrate production-grade engineering practices, not just CRUD.

- JWT auth with refresh token rotation and RBAC across Candidate, Recruiter, and Admin roles
- Async resume parsing via **BullMQ** background workers integrated with **AWS S3**
- **Redis caching** with event-based invalidation and cursor-based pagination on job listing endpoints
- **77 tests, 85%+ coverage** (Vitest/Supertest), Docker multi-stage builds, CI/CD via GitHub Actions
- Deployed across Render (API + worker), Neon PostgreSQL, Upstash Redis, and Vercel, with Sentry error monitoring

**Stack:** Node.js · Express.js · TypeScript · PostgreSQL (Prisma) · Redis · BullMQ · AWS S3 · Docker · React.js

🔗 [GitHub](https://github.com/w-aniket/HireFlow) · [Live Site](https://hire-flow-omega.vercel.app)
